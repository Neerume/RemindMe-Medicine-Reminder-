# RemindMe - Medicine Reminder App

RemindMe is a medicine reminder mobile application built using Flutter and Dart. It helps users keep track of their medication schedules and receive reminders on time through a simple and easy-to-use interface.

## Features

* Add and manage medications
* Set medication reminders
* Track medicine schedules
* User-friendly interface
* Secure user authentication

## Technologies Used

### Frontend

* Flutter
* Dart
* Android Studio

### Backend

* Node.js
* REST API
* Vercel (Deployment)

## Getting Started

1. Clone the repository

```bash
git clone https://github.com/Neerume/RemindMe-Medicine-Reminder-.git
```

2. Navigate to the project folder

```bash
cd RemindMe-Medicine-Reminder-
```

3. Install dependencies

```bash
flutter pub get
```

4. Run the application

```bash
flutter run
```
